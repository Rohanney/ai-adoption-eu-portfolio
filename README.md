# Who has adopted AI?

**Question:** Since 2021, has AI adoption by European businesses been broad-based, or has it stayed concentrated in large firms, the tech sector and a few countries?

This question is arguable: the same Eurostat data show adoption rising in every size class, sector and most countries (a "broad boom" reading), while also showing large gaps in the level of adoption (a "still concentrated" reading). The app sets out both and states which we find more convincing.

## Persona

**Maya, policy adviser at a national small-business association.** She has to decide whether to lobby for a targeted AI-adoption support program for small firms, and if so, which industries and whether her country is behind the EU as a whole.

## User stories

1. As Maya, I want to see how the AI adoption gap between small and large firms has changed in my country, so that I can judge whether small firms are falling behind. *(Page 2 · Firm size: choose a country.)*
2. As Maya, I want to see which industries have the lowest AI adoption and how much they have grown, so that I can target support at the sectors that most need it. *(Page 3 · Industries: choose a comparison year.)*
3. As Maya, I want to compare my country with the EU average in a chosen year, so that I know whether the gap is a national or an EU-wide problem. *(Page 4 · Countries: choose a year and countries.)*

## Run it

```bash
conda create -n a3 python=3.11 -y
conda activate a3
pip install -r requirements.txt
python -m src.data          # rebuilds data/processed/ from data/raw/
streamlit run app.py
```

To verify the Member 3 Industries data from the bundled original Eurostat samples:

```bash
python -m unittest discover -s tests -v
```

The Industry page supports two interactions (comparison year and industry selection), an empty-selection message, and two complementary charts: a labelled latest-year **ranking** and a labelled two-year **change** comparison. The group app also uses **time-series change** and **EU-baseline deviation** chart families. See `docs/industry_validation.md` and `docs/portfolio_checklist.md` before submission.

## Repository layout

| Path | What it is |
| --- | --- |
| `app.py` | Home page: question, persona, headline facts, answer, limits, sources |
| `pages/1_EU_trend.py` … `pages/4_Countries.py` | One page per group member |
| `src/common.py` | Shared data loading, colours and footer |
| `src/data.py` | Transform: `data/raw/*.csv` → `data/processed/*.csv`, with validation |
| `data/raw/` | Source samples exactly as downloaded from Eurostat |
| `data/processed/` | The tidy files the app reads (regenerated by `python -m src.data`) |
| `docs/data_dictionary.md` | Source, URL, licence, columns, units, keys, coverage, transform for every dataset |
| `docs/ai_provenance.md` | AI provenance matrix: one row per substantive AI use |
| `docs/disclosure.md` | Data and AI disclosure statement |
| `tests/test_industries.py` | Reproducible source-to-chart verification of all 44 industry observations |
| `docs/industry_validation.md` | Verified outputs, traceable numeric findings and interpretation limits |
| `docs/portfolio_checklist.md` | 30-check final portfolio preflight and unresolved group-wide tasks |
